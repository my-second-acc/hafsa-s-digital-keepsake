# Hafsa's Digital Keepsake

Build a beautiful, modern, fully responsive interactive birthday website for my best friend, Hafsa. 💗

The website should feel like a thoughtful digital birthday gift — cute, elegant, emotional, playful, and personal. It should NOT look like a generic birthday template. Take visual inspiration from the reference screenshots I provided: scrapbook-style memories, soft pastel colors, gift/surprise interactions, handwritten notes, polaroid photos, decorative elements, and a multi-section birthday journey.

IMPORTANT:
- The entire website must be fully responsive and look excellent on mobile, tablet, and desktop.
- Make the UI modern, polished, and visually consistent.
- Use tasteful animations, but don't overdo them.
- Avoid a childish/cartoonish appearance. The overall aesthetic should be cute + elegant + premium.
- Use high-quality typography, spacing, cards, shadows, subtle gradients, and smooth transitions.
- Make all sections feel connected as one birthday experience.
- Use placeholder images where necessary, but structure everything so I can easily replace them later.
- Do not use excessive emojis everywhere. Use them strategically.
- Make navigation and interactions actually work.

# RESPONSIVENESS

This is extremely important.

Desktop:
- Spacious layouts
- Large scrapbook compositions
- Multi-column cards
- Beautiful decorative positioning

Tablet:
- Adapt grids
- Reduce decorative elements where necessary

Mobile:
- Single-column layouts
- Properly sized typography
- Touch-friendly buttons
- Horizontal photo carousel where useful
- Navigation becomes a hamburger menu
- No horizontal scrolling
- No overlapping content that becomes unreadable
- Polaroids should stack naturally
- Modals should fit the screen
- Keep animations performant

Test the layout mentally across:
- 320px mobile
- 375px mobile
- 430px mobile
- tablet
- 1366px desktop
- large desktop screens
